# Changes

## 0.1.0

- Released the code under the MIT License.
- Added the recovered feature extractor, optional image pipeline, and an installable command-line interface.
- Exported the original feature tables and selected classifiers into portable CSV and JSON with source and artifact checksums.
- Added replay of recorded predictions, deterministic classifier refits, and the original RoT-DS validation folds.
- Documented historical geometry, dataset splitting, model selection, and the discrepancy between the paper’s validation mean and the saved scores.
- Added an illustration from the image pipeline, feature definitions, tests, and continuous integration.
